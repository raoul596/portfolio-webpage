Project Overview

Based on the grid tied inverter version 5 build by J. Fortherby. I want to experiment with this myself. For a future project I would like to be able to store solar energy in a battery and use this stored energy during peak hours to run my house. Because this is a hot topic at the time of writing I would like to get knowledge about inverter designs and software and how efficiency can be improved. Designing inverters is certenly not an easy topic, so this way I want to challenge myself.
