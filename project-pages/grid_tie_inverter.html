Project Overview

Based on the grid tied inverter V5 build by J. Fortherby. I want to experiment with this myself. For a future project I would like to be able to store solar energy in a battery and use this stored energy during peak hours to run my house. Because this is a hot topic at the time of writing I would like to get knowledge about inverter designs and software and how efficiency can be improved. Designing inverters is certenly not an easy topic, so this way I want to challenge myself.

Getting started

I first read about this project on Instructables. Here I saw multiple versions of the ivnerter and read all the guides made by J. Fortherby. Only the first four iterations are placed on Instructables. His future progress visit his site: jamesfotherby.com

Modifying the design

Because efficiency is importend for me I want to experiment with GaN type FETs, which J. Fortherby used in V4. According to his blog they exploded because the DFSDM analogue watchdog was not working in V4, which he fixed in V5. For me a reason to reintroduce the GaN type FETs! But I wanted to use his improved filtering used on V5, so I took the schematic of the V5 PCB and added the GaN FETs onto this design. Also I changed the PCB to my likings like a tag-connect for uploading and debugging the PCB. Also I did not like that some componenst were on the back side of the PCB, so I moved them over.

Initial testing

Before doing real test on mains power I tested the logic section of the PCB. Only problem I found was my linear regulator which is designed too small, so I soldered on a THT TO-220 sized linear regulator. I know these are not efficient, but for now they speed up prototyping. Later when everything works as excpected I will upgrade to a switched power supply.

First time putting power into the grid

Now everything on the low voltage side is working I used a 10:1 transformer, so I can start testing and keep the voltage on the PCB safe. Now I can test the Phase-Locked loop (PLL) for the first time which worked first time. The inverter even started to to push power back into the grid!
