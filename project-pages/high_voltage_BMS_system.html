FoxBMS 2

This project is based on the open source FoxBMS. The hardware was developed in Altium. Since we work to make this project open source we opted to choose KiCAD for PCB developement. So I converted the complete schematic and board layout into KiCAD.

CMU

The CMU is part of a battery module which consist of 14 cells, but can be configured up to 16 cells for LFP batteries. The CMU communicates with the FoxBMS over TPL, which is an proprietary isolated daisy chain protocol developed by NXP. The CMU also consist of balancing resistors and NTC's for temperature messurements.

Busbar PCB

Our aim is to create a as power dense battery as possible, while meeting the Lloyds standards regarding fire safety and ofcourse ease of assembly. The busbar PCB contains NTC's for temperature monitoring and pads where the battery cells can connect to. These all lead to the front of the battery where the CMU can be connected.

Battery emulator PCB

For software developed it would be safer and easier to have an emeulator which can simulate a battery module. This way during software development different battery states can be simulated directly.
